
# Doxygen Documentation

## 1. Introduction
Doxygen is a documentation generator
for programming languages such as C and C++.

## 2. Features
- Generates HTML documentation
- Generates LaTeX documentation
- Extracts comments from source code
- Documents classes and functions
- Creates class diagrams

## 3. Documentation Comment Example

/**
 * @brief Adds two integers.
 * @param a First integer.
 * @param b Second integer.
 * @return Sum of a and b.
 */
int add(int a, int b) {
    return a + b;
}

## 4. Important Commands

| Command | Purpose |
|---|---|
| doxygen -g | Generates Doxyfile |
| doxygen Doxyfile | Generates documentation |
| INPUT | Specifies source files |
| OUTPUT_DIRECTORY | Specifies output folder |
| EXTRACT_ALL | Extracts all entities |
