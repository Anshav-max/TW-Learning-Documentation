
# Git Commands Practical Guide

## 1. Repository Initialization

git init

## 2. Check Status

git status

## 3. Add Files

git add .
git add filename

## 4. Commit Changes

git commit -m "Initial commit"

## 5. View History

git log
git log --oneline

## 6. Branch Operations

git branch
git branch new-branch
git switch new-branch
git switch main

## 7. Remote Operations

git remote add origin REPOSITORY_URL
git remote -v
git push -u origin main
git pull origin main
git fetch origin

## 8. Other Commands

git clone REPOSITORY_URL
git diff
git stash
git tag
git rm filename

## 9. Conclusion

These commands are used to manage
repositories and track project changes.
