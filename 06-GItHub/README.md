
# GitHub Documentation

## 1. Introduction
GitHub is a cloud-based platform
for hosting and collaborating on Git repositories.

## 2. Features
- Repository hosting
- Collaboration
- Pull requests
- Issue tracking
- Project management

## 3. Important Concepts

### Repository
A location where project files and their
version history are stored.

### Commit
A saved snapshot of project changes.

### Push
Uploads local commits to GitHub.

### Pull
Downloads and integrates remote changes.

### Clone
Creates a local copy of a repository.
