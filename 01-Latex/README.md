
# LaTeX Documentation

## 1. Introduction
LaTeX is a document preparation system
used to create professional documents.

## 2. Applications
- Academic reports
- Research papers
- Technical documentation
- Mathematical equations

## 3. Basic Structure

\documentclass{article}

\begin{document}

Hello World!

\end{document}

## 4. Important Commands

| Command | Purpose |
|---|---|
| \title{} | Sets document title |
| \author{} | Sets author |
| \section{} | Creates section |
| \textbf{} | Bold text |
| \textit{} | Italic text |
