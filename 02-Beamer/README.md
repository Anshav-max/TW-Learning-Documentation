
# Beamer Documentation

## 1. Introduction
Beamer is a LaTeX document class used to
create professional presentations.

## 2. Features
- Professional presentation slides
- Mathematical equations
- Themes and colour customization
- Tables and images
- Overlays and animations

## 3. Basic Beamer Structure

\documentclass{beamer}

\title{My First Presentation}
\author{Your Name}
\date{\today}

\begin{document}

\begin{frame}
\titlepage
\end{frame}

\begin{frame}{Introduction}
Hello World!
\end{frame}

\end{document}

## 4. Important Commands

| Command | Purpose |
|---|---|
| \documentclass{beamer} | Creates presentation |
| \begin{frame} | Starts a slide |
| \end{frame} | Ends a slide |
| \title{} | Sets title |
| \author{} | Sets author |
| \titlepage | Displays title slide |
| \usetheme{} | Changes theme |
